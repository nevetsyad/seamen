# Seamen

A daily dive experience where you answer prompts to descend deeper into the ocean.

## How to Play

- Answer daily prompts (7 prompts per dive)
- Each prompt has a 25-second time limit
- Rarer answers sink you deeper
- Reach the deepest depths for the best scores

## Features

- Daily dives with fresh prompts
- Archive of past dives
- Themed packs for special experiences
- Friend system with interactions
- Multiple ocean zones (Surface, Midnight Zone, Abyssal Zone, Hadal Zone)
- Sound controls and settings

## Controls

- Click "BEGIN DESCENT" to start a dive
- Answer prompts within the time limit
- Use friend interactions for hints or support
- Adjust settings as needed

## Zones

- **Surface**: 0m - Starting point
- **Midnight Zone**: 67x surface pressure
- **Abyssal Zone**: Titanic rests at 3,800m
- **Hadal Zone**: 332m deepest dive possible
